# «Канон» — правила для Claude Code

Программа качества обучения для Центра стратегического развития ТГМУ им. Абуали ибни Сино.
Владелец — врач, не программист: отвечать по-русски, простыми словами; итог — что сделано, что проверено, что осталось.

## Запреты
- Репозиторий публичный: никаких паролей, ключей, адресов серверов, личных данных сотрудников и студентов.
  Секреты — только переменные окружения (`KANON_SECRET_KEY`, `KANON_DATABASE_URL`).
- Тексты WFME, ESG, ISO, AMEE не копировать — только номер пункта и своё краткое изложение.
- Никаких идентификаторов моделей ИИ в коммитах и коде.
- Анонимность студентов: ответы не связывать с личностью, итоги — только при числе ответов ≥ порога.

## Код
- Django 5.2 + серверные шаблоны (`templates/`), стили — `static/kanon.css`, цвета только через токены `var(--…)`.
- Приложения: `org` (структура), `accounts` (пользователи, роли, права — `accounts/permissions.py`),
  `norms` (нормы и уровни), `portfolio` (портфолио преподавателя), `instruments` (инструменты, расчёты — `instruments/scoring.py`),
  `inspections` (проверки, находки, «паутинка»; права — `inspections/access.py`),
  `capa` (проблемы качества, планы исправления),
  `feedback` (анонимные опросы студентов — `feedback/voting.py`; не добавлять связь кода с ответом, время ответа, IP),
  `dashboard` (панель, Стратегия 2030, отчёты Excel/Word — `dashboard/data.py`, `dashboard/reports.py`),
  `accreditation` (самооценка по IAAR, прогноз — `accreditation/readiness.py`), `core` (журнал изменений, начальные данные).
- Каждое изменение справочников пишется в журнал (`core.models.log`).
- Порог не задан → «проверить нельзя», а не «норма». Удаление с историей → предлагать «закрыть».
- Интерфейс на двух языках (ru/tg): весь новый текст — через `gettext` / `{% translate %}` (правила и словарь —
  `docs/ПЕРЕВОД.md`); после правок: `makemessages -l tg --ignore=".venv/*"`, перевести, `compilemessages`, закоммитить .po и .mo.

## Проверка
- Тесты: `KANON_DEBUG=1 .venv/bin/python manage.py test` (все должны пройти перед коммитом).
- Каждое исправление закрепляется тестом.
- Документы: `docs/КОНЦЕПЦИЯ.md`, `docs/МОДЕЛЬ_ДАННЫХ.md`, `docs/САЙТ_ТГМУ.md`, `docs/ИССЛЕДОВАНИЕ_GITHUB.md`, `docs/ПЛАН.md`.
