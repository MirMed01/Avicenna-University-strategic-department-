# Концепция: автоматизация Отдела стратегического развития и качества обучения ТГМУ

Черновик для обсуждения. Всё, что ниже помечено «предположение», нужно подтвердить.

## 1. Зачем

Сейчас работа отдела, как правило, держится на Word, Excel и бумаге (предположение). Из-за этого:
- данные от кафедр и факультетов собираются вручную и с опозданием;
- к аккредитации и отчётам в министерство документы ищут заново;
- выполнение стратегического плана трудно увидеть одним взглядом;
- анкетирование студентов и выпускников разбирают вручную.

Цель программы — **одно место**, где кафедры сдают данные, а отдел видит картину, считает показатели
и получает готовые отчёты.

## 2. Кто будет работать (роли)

| Роль | Что делает в программе |
|---|---|
| Руководство (ректор, проректоры) | Смотрит сводную панель показателей, без ввода данных |
| Сотрудник отдела | Ставит задачи, проверяет сданные данные, формирует отчёты |
| Декан / зав. кафедрой | Сдаёт отчёты и показатели своего подразделения, видит свой рейтинг |
| Преподаватель | Заполняет личный отчёт (нагрузка, публикации, повышение квалификации) |
| Студент / выпускник / работодатель | Отвечает на анкеты (анонимно) |

## 3. Модули (кандидаты)

1. **Стратегический план и показатели (KPI).** Цели → задачи → показатели → ответственный → срок →
   факт. Светофор «в срок / под угрозой / сорван». Сводная панель для руководства.
2. **Рейтинг преподавателей и кафедр.** Ежегодная сдача данных по утверждённым критериям, автоматический
   подсчёт баллов, подтверждающие файлы, проверка отделом.
3. **Анкетирование.** Конструктор анкет («Преподаватель глазами студентов», удовлетворённость выпускников,
   отзывы работодателей), рассылка по ссылке, автоматические итоги по кафедрам.
4. **Аккредитация и самооценка.** Стандарты (национальные и, при необходимости, WFME для медицинского
   образования) → критерии → кто отвечает → доказательства (файлы) → готовность в процентах.
5. **Внутренний аудит кафедр.** План проверок, чек-листы, замечания, план исправлений и контроль сроков.
6. **Мониторинг учебного процесса.** Успеваемость, итоги сессий, ГИА, отсев — загрузка из Excel,
   графики по годам и факультетам.
7. **Отчёты.** Готовые формы (годовой отчёт отдела, отчёты в министерство) в Word/Excel/PDF по кнопке.
8. **Документы отдела.** Положения, приказы, регламенты с версиями и поиском.

Языки интерфейса: русский и таджикский (английский — для международной аккредитации; предположение).

## 4. Предлагаемый порядок работ

Не всё сразу. Предлагаю начать с того, что даёт пользу быстрее всего:

| Этап | Что | Результат |
|---|---|---|
| 0 | Сбор требований: текущие формы, Excel-таблицы, критерии рейтинга | Список полей и отчётов |
| 1 (MVP) | Вход по ролям + **Стратегический план и KPI** + **Анкетирование** | Работающий сайт для отдела |
| 2 | Рейтинг ППС и кафедр | Рейтинг считается сам |
| 3 | Аккредитация и аудит | Папка доказательств и готовность |
| 4 | Мониторинг учебного процесса и готовые отчёты | Отчёт по кнопке |

## 5. Техника (предложение)

- Веб-приложение (открывается в браузере, на компьютере и телефоне, ничего не нужно устанавливать).
- Стек тот же, что в МирМед (Vite + JavaScript, бэкенд на Python), — чтобы одна команда могла сопровождать
  оба проекта.
- База данных: PostgreSQL. Размещение — на сервере университета или на отдельном VPS (решает владелец).
- Персональные данные студентов и сотрудников — только на сервере в Таджикистане/университете,
  анкеты — анонимные.
