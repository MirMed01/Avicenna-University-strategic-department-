# Перевод интерфейса на таджикский язык

Языки: русский (исходный) и таджикский (`tg`). Переключатель — в шапке каждой страницы.
Переводится **интерфейс**. Не переводятся: журнал изменений, введённые данные (названия кафедр, тексты стандартов,
находки, комментарии). Для анкет студентов есть отдельные таджикские поля вопросов.

## Правила разметки
- Python, уровень модуля (модели, choices, формы): `from django.utils.translation import gettext_lazy as _`.
- Python, внутри функций (сообщения, тексты отчётов): `from django.utils.translation import gettext as _`.
- С переменными — только именованные подстановки: `_("Удалено: %(name)s") % {"name": x}`; f-строки внутри `_()` нельзя.
- Шаблоны: `{% load i18n %}`; `{% translate "..." %}`; с переменными — `{% blocktranslate with a=b %}…{{ a }}…{% endblocktranslate %}`.
- msgid — **ровно прежний русский текст**, чтобы русская версия не изменилась (тесты это проверяют).
- Текст журнала (`log(...)`) и сохраняемые в базу тексты — не размечать.
