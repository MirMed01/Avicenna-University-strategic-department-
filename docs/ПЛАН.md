  - Отчёты по кнопке: Excel (4 листа, openpyxl) и годовой отчёт Центра в Word (python-docx). 110 тестов.
- **15.10.2026 — Этап 5: окно студентов.**
  - Опросы по одноразовым кодам: листок с QR (segno, BSD) — разрезать и раздать вслепую; вход без учётной записи.
  - Анонимность по схеме EvaP (MIT; схема, код свой — EvaP рассчитан на учётные записи студентов):
    код знает только «использован», без времени и связи с ответом; оценки — счётчики; комментарии — со случайным
    UUID и показываются кафедре только после одобрения Центром; итоги — только при числе ответов ≥ порога (не меньше 3).
  - Код гасится в одной транзакции с записью ответа; без обязательных ответов код не тратится.
  - Итоги: средние, распределения, доля «да», расчётный показатель и сравнение с нормой кафедры.
  - Образец анкеты «Преподавание глазами студентов» и показатель СТ-1; студенческие анкеты не попадают в проверки.
  - Codespaces: ссылки в QR — на внешний адрес https (X-Forwarded-Host). 105 тестов.
- **15.10.2026 — Этап 4: диагнозы и лечение.**
  - Справочник проблем качества (11, образец — утвердить в Центре): признаки, типовые мероприятия,
    подсказка диагноза по отклонившемуся показателю (★); диагноз ставит эксперт.
  - План исправления из находки: анализ причины, мероприятия (вид, исполнитель, срок), критерий «помогло».
  - Ход плана по образцу модулей ISO (OCA, только идея): черновик → на утверждении → выполняется →
    проверка результативности → закрыт / снова в работе / отменён. Подать — только с анализом и мероприятиями;
    «выполнены» — только когда все отмечены; закрыть или вернуть — только с комментарием.
  - Повторная проверка из плана теми же инструментами; её значение показателя видно в плане («было / стало»).
  - Просроченные мероприятия — на главной; находку с планом нельзя удалить; вся история в журнале. 89 тестов.
- **15.10.2026 — Этап 3: проверки кафедр.**
  - Назначение проверки (подразделение, ведущий эксперт, срок, инструменты); статусы: назначена → сбор данных →
    разбор → закрыта (или отменена), возврат на сбор — только с комментарием; всё в журнале.
  - Заполнение: кафедра — то, что адресовано ей, эксперты — остальное; черновик и сдача, обязательные пункты.
  - Расчёт при закрытии сбора: показатели сравниваются с уровнем строгости этой кафедры, несколько заполнений
    усредняются; отклонения → находки «лёгкое» / «выраженное»; нет порога — «проверить нельзя», не находка.
  - «Карта здоровья» (паутинка) и находки эксперта; проверки видны на странице подразделения.
  - Демо-режим: готовая проверка с демо-порогами (помечены «не утверждён»).
  - Исправлено: координаты «паутинки» в русской локали писались с запятой и ломали рисунок (тест на дефект).
- **15.10.2026 — Этап 2: инструменты.**
  - Конструктор инструментов: разделы, пункты (да/нет, шкала 1–5, число, выбор, текст), веса, привязка к показателю.
  - Расчётные показатели: доля (пункт ÷ пункт), доля «да», баллы в % от максимума. Нет данных — «посчитать нельзя».
  - Версии: опубликованная не меняется; правка — через новую версию (копия), старая уходит в архив.
  - Пробное заполнение с расчётом и сравнением с порогами (ничего не сохраняет).
  - Загружены 4 инструмента: годовой отчёт кафедры (по Положению 2018), готовность к ОСКЭ и оценочный лист
    станции (по Положению 2020), протокол посещения занятия (образец — утвердить на УМС).
  - Новый документ норм «Внутренние положения ТГМУ» (9 показателей, пороги не заданы — их задаёт Центр).
  - Справочник норм показывает, каким инструментом измеряется показатель. 58 тестов.
