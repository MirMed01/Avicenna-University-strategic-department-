## Закрыто (последнее сверху)
- **15.10.2026 — Этап 2: инструменты.**
  - Конструктор инструментов: разделы, пункты (да/нет, шкала 1–5, число, выбор, текст), веса, привязка к показателю.
  - Расчётные показатели: доля (пункт ÷ пункт), доля «да», баллы в % от максимума. Нет данных — «посчитать нельзя».
  - Версии: опубликованная не меняется; правка — через новую версию (копия), старая уходит в архив.
  - Пробное заполнение с расчётом и сравнением с порогами (ничего не сохраняет).
  - Загружены 4 инструмента: годовой отчёт кафедры (по Положению 2018), готовность к ОСКЭ и оценочный лист
    станции (по Положению 2020), протокол посещения занятия (образец — утвердить на УМС).
  - Новый документ норм «Внутренние положения ТГМУ» (9 показателей, пороги не заданы — их задаёт Центр).
  - Справочник норм показывает, каким инструментом измеряется показатель. 58 тестов.
- **14.10.2026 — Этап 1.**
  - Вход по email, саморегистрация с подтверждением, 8 ролей с правами по структуре.
  - Структура ТГМУ (5 факультетов, 59 кафедр): добавить / изменить / перенести / закрыть / удалить пустое.

  - Портфолио преподавателя: записи с файлами, отправка на проверку, подтверждение заведующим / деканом / Центром,
    сводка по показателям Стратегии.
