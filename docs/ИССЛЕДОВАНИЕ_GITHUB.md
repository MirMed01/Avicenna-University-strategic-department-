# Исследование: готовые открытые модули (образование и медицина)

Проверено 14.10.2026 по публичным страницам GitHub. Звёзды (★) примерные. Сайты wfme.org, iso.org и amee.org
в день проверки не открылись, поэтому сведения о стандартах взяты из вторичных источников.

## Главный вывод

Готовой открытой системы «аккредитация и качество медицинского вуза» нет. Также нет открытых модулей
для OSCE, EPA и электронного портфолио. Ядро «норма → проверка → диагноз → лечение» придётся
делать самим. Для отдельных частей есть хорошие образцы и готовые библиотеки.

## Что запасным вариантом или не берём

- **LimeSurvey** (GPL), **Formbricks** (AGPL, часть кода под корпоративной лицензией), **KoboToolbox** (AGPL).
  Подходят только как отдельный сервер анкет рядом с программой.
- **OpenEduCat**, **Frappe Education**. Это ERP вуза на Odoo или ERPNext. Брать их значит сменить платформу.
- **Open edX** для нас тяжёл. **Fedena** устарела. Mahara (портфолио): зеркало на GitHub заархивировано.
- Мелкие проекты по аккредитации (Питтсбург, Django-проекты) дают только идеи:
  - «заморозка» учебного года перед аудитом;
  - цепочка согласования «программа → декан → отдел качества».
- «Online Accreditation Management System v1.0» не брать: в нём известна уязвимость (SQL-инъекция).

## Что это меняет в концепции

1. **Справочник норм должен иметь версии.** Сейчас идёт пересмотр ESG (ESG 2027, утверждение ожидается
   в мае 2027 года). У WFME до 2020 года было 9 областей, а теперь 8.
2. **Цикл CAPA строим по образцу ISO 21001 (раздел 10) и модулей OCA**:
   несоответствие → причина → действие → срок → проверка результативности.
3. **Один формат (JSON) для всех инструментов**: анкеты, чек-листы, протоколы посещения, станции OSCE.
4. **Анализ экзаменов делаем на своём Python**: классические индексы — это десятки строк,
   IRT берём из girth.

## Проверка нормативов (вторичные источники)

- **WFME 2020, 8 областей:**
  1. Миссия и ценности
  2. Образовательная программа
  3. Оценка студентов
  4. Студенты
  5. Академический штат
  6. Образовательные ресурсы
  7. Обеспечение качества
  8. Управление и администрирование
- **ISO 21001:2018.** Разделы 4–10: контекст, лидерство, планирование, поддержка, деятельность, оценка
  результатов, улучшение. 11 принципов, среди них ориентация на обучающихся, процессный подход, решения на основе
  фактов, доступность и равенство, этика, защита данных.
- **AMEE ASPIRE:**
  - подтверждены области: оценка студентов, вовлечённость студентов, социальная ответственность, развитие
    преподавателей, симуляция, разработка программ, технологии в обучении;
  - полный актуальный список проверить не удалось.
- **ESG 2015, часть 1:** 10 стандартов, от 1.1 «Политика обеспечения качества» до 1.10 «Циклическая
  внешняя оценка».
