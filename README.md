# Канон (Қонун · QANUN)

Название — в честь «Канона врачебной науки» Абуали ибни Сино: программа сверяет образование с нормами, как врач — организм с нормой.

Программа мониторинга и улучшения качества образования для **Отдела стратегического развития и качества обучения**
ТГМУ имени Абуали ибни Сино (Душанбе).

Состояние: **этапы 1–6 готовы, плюс аккредитация IAAR и таджикский язык** — структура университета (с правкой), пользователи и роли, справочник норм
с уровнями строгости, портфолио преподавателя, конструктор инструментов (отчёт кафедры, ОСКЭ, посещение занятий), проверки кафедр с профилем показателей кафедры, выводы проверок и планы исправления, анонимные опросы студентов по QR-кодам,
панель руководства с тепловой картой и мониторингом Стратегии 2030, отчёты в Word и Excel,
подготовка к аккредитации IAAR (124 критерия), реестр процессов СМК (университет, факультет, кафедра — с подпроцессами и 26 инструментами оценки) с картой рисков, классификатор проблем (10 групп),
анализ экзаменационных тестов, история показателей по годам, страница «Настройки» для Центра, интерфейс на русском и таджикском. План — [`docs/ПЛАН.md`](docs/ПЛАН.md).

## Показать программу через GitHub (Codespaces)

1. Откройте репозиторий на GitHub → зелёная кнопка **Code** → вкладка **Codespaces** → **Create codespace**.
2. Подождите 3–5 минут: GitHub сам установит программу, загрузит структуру ТГМУ и создаст демо-входы.
3. Откроется вкладка с «Каноном» (если нет — внизу вкладка **Ports**, строка «Канон», значок глобуса).
4. Логины и пароль: в терминале Codespace наберите `cat .demo-logins.txt`.
   Входы: директор Центра, ректор, декан, заведующий кафедрой, преподаватель (у всех один пароль).
5. Чтобы показать коллегам: вкладка **Ports** → правый щелчок по «Канон» → **Port Visibility → Public**,
   затем скопируйте адрес. Ссылка работает, пока Codespace запущен.

**Обновить уже созданный Codespace** (а не создавать новый): в терминале Codespace —
`git pull`, затем `python manage.py migrate` и `python manage.py load_initial_data`, потом обновите страницу (F5).
Программа сама узнаёт, что работает в Codespaces, поэтому старый Codespace пересоздавать не нужно.

Codespace засыпает через 30 минут без работы. Бесплатно — около 60 часов в месяц. Данные демо живут
только в этом Codespace. Для постоянной работы нужен свой сервер.

## Как запустить (для разработчика)

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
export KANON_DEBUG=1                      # только для разработки; на сервере — KANON_SECRET_KEY и KANON_DATABASE_URL
.venv/bin/python manage.py migrate
.venv/bin/python manage.py load_initial_data   # структура ТГМУ, Стратегия 2030, каркасы WFME/ESG/ISO
.venv/bin/python manage.py createsuperuser     # первый администратор
.venv/bin/python manage.py runserver           # http://127.0.0.1:8000
.venv/bin/python manage.py test                # тесты
```

Переменные окружения для сервера: `KANON_SECRET_KEY`, `KANON_DATABASE_URL` (PostgreSQL),
`KANON_ALLOWED_HOSTS`, `KANON_CSRF_ORIGINS`, `KANON_MEDIA_ROOT`, `KANON_PUBLIC_URL` (адрес для QR-кодов студентам),
`KANON_USE_X_FORWARDED_HOST=1` (если сервер стоит за прокси).
